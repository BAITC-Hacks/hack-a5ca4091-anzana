# 💸 Gove.AI Crypto Tax

Модуль автоматического расчёта налога на криптоактивы для Республики Казахстан.  
Показываем Комитету государственных доходов, как на сделке фиксируются **точный курс** и **актуальная налоговая база**.

> [!IMPORTANT]
> Цена актива и курс **USD/KZT** записываются на секунду сделки. Дальше модуль сам считает прирост и налог. Вручную курс подбирать не нужно.

| | |
|---|---|
| 🇰🇿 Страна | Казахстан |
| 🏛 Для кого | КГД |
| 📈 Метод | FIFO |
| 💰 Налог | ИПН 10% |
| 🎯 Демо 2025 | **393 868 ₸** |

## 🎯 Задача

> [!WARNING]
> Курс криптоактива и курс доллара к тенге меняются постоянно. Вручную зафиксировать цену сделки почти невозможно.

Из-за этого происходит сразу три вещи:

- 📉 в декларацию попадает примерная цифра;
- 🕶 доход остаётся в тени;
- 🏛 КГД не получает точных и своевременных данных, бюджет недобирает налог.

## ✅ Что сделали

- 🎤 Собрали презентацию продукта и живой демонстрационный модуль.
- ⏱ На каждую сделку записали цену актива и курс USD/KZT с точностью до секунды.
- 🧮 Посчитали прирост стоимости методом FIFO и ИПН по ставке 10%.
- 📄 Собрали декларацию: доход, расход, база и сумма налога.
- 📂 Добавили демо-портфель, импорт реестра и выгрузку в CSV.
